## Design Context

### Users
People managing proxy profiles, routes and connections on desktop and Android. Common tasks are connecting, switching nodes, updating subscriptions and inspecting network activity.

### Brand Personality
Calm, precise and lightweight. The user explicitly selected `codexc-flutter` as the visual reference and confirmed its icon style.

### Aesthetic Direction
Follow Codexc's neutral surfaces, fine separators, native Chinese typography and official Lucide outline icons. Use a 24-unit vector grid with 1.5-unit strokes, scaled with the icon. Keep the Cloudrift accent and identity. Both light and dark modes matter. Transparent mobile system bars must follow theme brightness while interactive content respects safe areas.

### Design Principles
- Use one shared vector icon renderer and semantic icon names across every page.
- Set page titles at 24/600, row titles at 14–16/500, body at 14–15/400 and metadata at 12–13/400; Chinese letter spacing is zero.
- Use restrained radii, thin borders and clear spacing. Reserve accent color for selection, actions and meaningful status.
- Keep mobile controls accessible and desktop controls compact. Support larger text, keyboard focus and reduced motion.
- Apply the shared theme to editors, dialogs and settings as well as the main workspace.
