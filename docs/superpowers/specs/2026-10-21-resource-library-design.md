# dclash 资源库与 Profile Builder 选择器设计

## 目标

为 dclash 增加可复用资源库，覆盖代理资源、规则集资源、正则过滤器和图标集。资源可以在工具页维护，并在 Profile Builder 中选择引用。资源库使用现有 GetX、JSON 持久化和备份体系，保持原有配置编辑器对未知字段的保留能力。

## 范围

本阶段实现四类资源：

- 代理资源：可复用的代理节点或代理片段。
- 规则集资源：Clash-compatible rule-provider 内容或 URL。
- 正则过滤器：用于筛选节点/名称的正则表达式集合。
- 图标集：节点或代理组的图标映射集合。

每条资源支持 `url`、`file`、`inline` 三种来源。远程刷新仅提供手动触发；自动刷新策略和冲突合并留到后续阶段。

## 数据模型

新增 `ResourceKind`、`ResourceSourceType` 和不可变 `ResourceItem` 领域模型。`ResourceItem` 包含稳定 id、名称、类型、来源类型、来源值、内容摘要/内容、启用状态、排序值、创建/更新时间以及 `extra` 扩展字段。序列化使用版本化 envelope：

```json
{
  "version": 1,
  "items": [
    {
      "id": "...",
      "name": "...",
      "kind": "proxy",
      "sourceType": "url",
      "source": "https://...",
      "content": null,
      "enabled": true,
      "order": 0,
      "createdAt": "...",
      "updatedAt": "...",
      "extra": {}
    }
  ]
}
```

读取时保留未知顶层和条目字段，遇到损坏条目跳过并留下可恢复的原始 JSON；不接受空名称、空来源或不合法正则。内容和 URL 不写入日志。

## 服务与持久化

新增 `ResourceLibraryService`，负责初始化、列表排序、创建/更新/删除、启用切换、手动刷新、内容解析和引用校验。服务通过 `SettingsService` 的 `resources` 字段持久化，沿用设置的原子写入语义；服务外不直接修改资源 JSON。

资源刷新使用有界 HTTP 客户端和临时内容，不覆盖旧内容直到下载、状态码和类型校验完成。URL 失败时保留旧内容并向 UI 返回可读异常。文件来源由平台文件选择器读取，内联来源直接校验。

`BackupService` 的设置备份导出/恢复纳入 `resources`。恢复前校验版本、条目 id/类型/来源，并在一次原子设置恢复中替换资源库；非法恢复不得部分覆盖现有库。

## UI 与数据流

工具页新增“资源库”入口，使用四类筛选标签和搜索框。列表项显示名称、类型、来源、启用状态、更新时间，并提供编辑、刷新、启用/停用和删除。新增/编辑对话框根据类型显示必要字段；正则和 YAML 内容提供多行编辑与语法错误提示。

`ResourceLibraryController` 只负责页面状态和对话框编排，服务负责业务。所有异步失败通过现有 `showAppError` 展示，空状态使用 `AppEmpty`，样式沿用 codexc 风格的细线图标、沉浸式状态栏和现有主题变量。

Profile Builder 增加资源选择器：代理资源可作为代理片段导入，规则集资源写入 `rule-providers` 引用，正则过滤器用于节点筛选，图标集用于代理/代理组的图标字段。选择器只写入 `ProfileBuilderDraft` 的编辑叶节点，生成配置时保留未编辑字段和未知字段。资源被删除后，已有配置仍保留生成后的内容；选择器只提示引用已失效，不静默删除配置。

## 校验与错误处理

- 名称在同类资源中不得重复；id 永不复用。
- URL 仅允许 HTTP/HTTPS，下载受大小、超时和重定向上限约束。
- 正则在保存前编译验证，单条失败阻止保存并定位条目。
- YAML 资源必须是对象或数组的有效 YAML，拒绝空文档。
- 启用资源在生成配置时按 order 稳定排序，失败时报告资源名称和类型。
- 任何失败都保留上一份有效持久化内容。

## 测试与验收

新增模型序列化/未知字段保留、正则/YAML 校验、资源 CRUD 和排序、刷新失败保留旧内容、备份恢复原子性、Profile Builder 选择器接入和资源删除后的失效引用测试。新增工具页和选择器的手机/桌面布局测试。完成后运行 `flutter analyze`、`flutter test`、`make check`、`make macos` 与 `make dmg`；Android 继续用 Mumu 做启动、导入和资源页回归，不启动真实 VPN。

## 非目标

本阶段不实现后台定时刷新、跨设备同步、WebDAV 资源冲突合并、完整图标下载缓存、全量代理协议可视化编辑以及系统代理/TUN 权限策略改动。
