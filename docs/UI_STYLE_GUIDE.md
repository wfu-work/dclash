# Cloudrift 界面规范

本轮参考 `codexc-flutter` 的界面规范、原生字体选择及 Lucide 图标绘制方式。保留云渡品牌和可选主题色，使用中性表面、细分隔线和更轻的文字层级。

## 图标

- 全部应用图标通过 `AppIcon` / `AppIcons` 使用官方 Lucide 1.17.0 路径，保持 24 单位坐标系、1.5 单位线宽、圆角端点与转角。
- 常规图标 20dp，侧栏 18dp，底部导航 21dp，辅助操作 16dp。线宽随尺寸等比缩放；不使用模糊或降低整个控件透明度来制造细线效果。
- 主题、禁用色、读屏标签和方向由公共绘制组件处理；返回、关闭、下拉、排序勾选及更多菜单也使用同一套图标。
- `AppIconPaths` 按需解析并缓存。每个上游 SVG 元素单独解析后合并，避免相对坐标继承前一个元素的位置。
- 新图标保留上游几何和许可，不手绘近似图形。许可见 `third_party/lucide-icons-LICENSE.txt`，应用开源许可页也提供该说明。

## 排版

| 用途 | 字号 / 字重 | 行高 |
| --- | --- | --- |
| 页面标题 | 24 / 600 | 1.3 |
| 卡片主标题 | 18 / 500 | 1.4 |
| 条目标题 | 14–16 / 500 | 1.4 |
| 正文 | 14–15 / 400 | 1.5 |
| 说明 | 13 / 400 | 1.45 |
| 标签与辅助信息 | 12–13 / 400 | 1.3–1.35 |
| 流量数字 | 28 / 500 | 1.25 |

常规中文字距为零；数值使用等宽数字特性，代码编辑器保留 JetBrains Mono。macOS 优先 Apple System / 苹方，Windows 使用 Segoe UI / 微软雅黑，Android 使用系统字体及中文回退。字号跟随系统缩放，不统一缩小页面。

## 表面与布局

- 浅色使用接近白色的主内容区、白色卡片与中性灰侧栏；深色使用独立的窗口、内容和卡片灰阶。主题色用于操作、选中和实际状态。
- 控件圆角 8dp，卡片 12dp，桌面内容表面 16dp，常规边框 0.5dp；避免装饰性阴影。
- 桌面侧栏 208dp，内容区保留 8dp 外边距。窄屏使用底部导航，安全区底色与内容衔接。
- 页面内边距手机 16dp、桌面 24dp；设置与工具页最大宽度 820dp。
- 窄屏页面操作放到标题下方，出站模式支持换行，空状态可滚动，配置与节点卡片按文字缩放增加高度。手机控件继续保留原生点击区域。

## 沉浸式系统栏

Android 使用 edge-to-edge，状态栏、系统导航栏和分隔线透明，关闭系统额外对比度遮罩。`AppSystemUi` 在整个导航器外提供随深浅主题切换的图标亮度，标准 AppBar 复用同一定义。

系统时间、电量与导航仍然可见。页面背景延伸到系统栏，SafeArea 继续避让标题和按钮；不靠移除安全区制造沉浸效果。原生启动主题也使用对应的背景与系统图标亮度，减少启动阶段的底色跳变。

具体检查结果见 [界面验证记录](ui-polish-verification.md)。
